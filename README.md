## “日本 VPS”和“日本 CN2 VPS”不是一回事

同样标着东京机房，回国体验能差出很多。差别在回国那一段走什么线路。

CN2 是中国电信的下一代承载网，AS4809。CN2 GIA 是其中优先级最高的一档，回程强制走 AS4809。CN2 GT 只在国际段走 CN2，国内段可能切回 163 骨干网，晚高峰容易拥堵。普通国际 BGP 则完全走当地运营商的常规出口。

一份第三方对恒创日本节点的路由测评值得参考：电信去程走 59.43 的 CN2 节点直连东京，回程全程 CN2；联通去程走 CN2、回程直连；移动去程 CMI，回程经 NTT 到香港后直连回国。这个组合下，电信用户的体感最好，联通和移动走各自优化线路，延迟和稳定性在可接受范围，但不是纯 CN2。

同一份测评给出的三网延迟是电信 56–76ms、联通 84–93ms、移动 89–92ms，晚高峰 ping 值没有明显漂移。这组数字只代表测评者当时的网络环境，换到你的城市、你的运营商，结果会不一样。

所以看到“日本云服务器”这四个字先别急着比价，先确认两件事：回程走不走 CN2 GIA，去程和回程是不是都优化过。只优化去程的机器，你上传快、用户下载慢，建站体验会很别扭。

## 你的场景该从哪一档起步

不用纠结配置表，按业务倒推就行。

日均访问量 1000 IP 以内的文字站、个人博客、轻量 API，1核1G 或 1核2G 配 2M 带宽足够。WordPress 加几个插件跑日均几百 IP 没问题，别指望它扛并发。

图片多的展示站、WooCommerce 或 Magento 这类电商程序，2核4G 配 5M 起步。2M 带宽加载商品图会明显拖慢首屏，转化率掉下去省下的那点钱不值。

多容器部署、中型数据库、需要跑定时任务的 API 服务，4核8G 是合理档位，带宽按实际出口流量选 5M 或 10M。

站群、高 IO、需要大量独立 IP 的场景，云服务器不合适，看独立服务器。恒创的日本独立服务器 298 元/月起，站群机型带 124–254 个 IP、1170 元/月起；LightLayer 东京的 E3-1230 配 16G 内存、240G SSD 加 1T HDD、20Mbps 起，$75/月。这些只是品类提示，具体配置还得自己核。

## 常见问题

**日本云服务器需要备案吗？** 不需要。香港、日本、美国、韩国这些海外节点都不受 ICP 备案管辖，开通即用。这是很多人选日本而不是国内机房的主要原因之一。

**延迟到底是多少？** 商家宣称的口径是 30–120ms，第三方测评给出的三网数据是 56–93ms。这些数字都产生在别人的网络里。你在内地哪个城市、用哪家运营商，实际延迟要自己 ping 过才算。

**2M 带宽够不够用？** 文字为主的站点，日均一千 IP 以内够。带图、带视频、带下载的不够。恒创的带宽是独享不是共享，2M 就是稳定的 2M，这一点比标称 100M 但共享的机型好判断。

**能不能退款？** 各家不同。恒创 3 天内、每年 1 次、每次 1 个产品，用券订单不退。天下数据只写“规定时间内支持无条件退款，具体咨询客服”。LightLayer 的第三方记录是“仅提供商责任”，也就是非商家原因不退款，下单前值得在账户里确认一遍当期条款。

**续费会不会涨？** 活动价套餐续费通常恢复原价，除非保持相同计费周期。天下数据写续费价与购买价一致。买之前把续费价问清楚，比首年便宜几十块重要得多。
